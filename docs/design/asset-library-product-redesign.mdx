# Taiyi 素材体系改进 PRD

状态：待评审，未实施。

本文定义 Taiyi 素材体系的产品概念、信息架构、用户流程、状态规则、异常反馈、分期范围和验收标准。本文只描述产品目标与行为，不代表现有实现已经具备这些能力。

## 1. 背景

当前产品已经具备账号级素材库、项目资产库、画布素材引用、生成结果自动保存、资源存储、素材分类、文件夹、回收站、Eagle 外部素材库和项目资产版本等能力。

现有能力由不同业务阶段逐步叠加，用户在使用时需要同时理解以下概念：

- 图片、视频、音频、文本和 3D 模型等媒体类型。
- 角色、场景、道具、参考等业务分类。
- 用户创建的自定义分类。
- 草稿、待确认、已确认、归档等状态。
- 账号素材、项目素材、画布节点和镜头产物之间的关系。
- 本机缓存、服务器和对象存储之间的同步状态。

这些维度目前在界面中缺少清晰分工。“素材”既代表一份实际文件，也代表数据库记录、项目引用、画布节点和用户主动收藏的内容。结果是用户难以判断素材从哪里来、保存在哪里、属于哪个项目、删除后影响什么，以及为什么生成成功后仍会提示同步失败。

## 2. 产品目标

本次改进需要达到以下目标：

1. 用户能够区分临时生成结果、当前项目素材和跨项目复用素材。
2. 用户能够在素材详情中查看并管理素材与项目、画布、镜头的关系。
3. 用户能够理解媒体类型、素材用途和文件夹各自解决的问题。
4. 生成成功后，即使保存或同步失败，用户仍能找回结果并单独重试失败步骤。
5. 删除、移出项目、取消收藏和彻底删除具有明确且不同的影响范围。
6. 素材量增长后，仍然可以通过项目、媒体类型、用途、文件夹、标签和关键词快速定位。

## 3. 非目标

本次改进不包含：

- 多用户团队空间、成员权限和跨账号共享素材。
- AI 自动打标签、以图搜图和重复素材识别。
- 独立数字资产管理系统需要的版权合同、授权期限和供应商结算。
- 替换现有资源存储供应商或强制用户配置 OSS。
- 改造 Eagle 自身的文件夹和标签体系。

这些能力可以建立在本次统一后的素材模型之上，作为后续版本规划。

## 4. 目标用户与核心任务

### 4.1 个人创作者

希望快速找到曾经使用或收藏的角色、场景和参考图，在新项目中继续使用，不关心底层文件保存在哪种存储中。

### 4.2 项目制作人员

希望围绕当前项目管理角色、场景、道具和镜头产物，确认版本，查看哪些镜头正在使用某份素材，并避免误删在用内容。

### 4.3 素材管理员

希望批量上传、分类、移动、归档和清理素材，了解容量占用以及同步失败情况。

## 5. 概念定义

产品界面统一使用以下概念：

| 概念 | 用户含义 | 示例 |
| --- | --- | --- |
| 临时结果 | 已生成或已上传，但用户尚未决定是否保留的内容 | 一次生图产生的四张候选图 |
| 项目素材 | 已加入一个或多个项目，可被章节、镜头或画布引用的内容 | 《山海》项目中的女主角三视图 |
| 我的素材 | 用户主动收藏，可跨项目复用的内容 | 常用水墨风格参考图 |
| 媒体类型 | 文件或内容的技术形态，由系统确定 | 图片、视频、音频、文本、3D 模型 |
| 素材用途 | 内容在影视创作中的语义角色，可由用户修改 | 角色、场景、道具、参考、其他 |
| 文件夹 | 用户自定义的整理方式，不改变素材用途 | 武侠人物、客户 A、待处理 |
| 项目引用 | 项目对素材的引用关系，不复制实际文件 | 素材同时加入项目 A 和项目 B |
| 使用位置 | 素材在项目内的具体使用地点 | 第一章、镜头 03、画布“分镜草图” |
| 同步状态 | 素材记录和实际文件是否已安全保存 | 已同步、正在同步、仅本机、同步失败 |

“业务分类”统一改称“素材用途”，“我的分类”统一改称“文件夹”。

## 6. 信息架构

### 6.1 工作台素材中心

侧边栏保留“素材”入口，进入账号级素材中心。素材中心包含：

- 我的素材：用户主动收藏、可跨项目复用的素材。
- 项目素材：按项目查看已加入项目的素材。
- 临时结果：未采用的生成结果和临时上传内容。
- 外部素材：Eagle 等插件提供的外部来源。
- 回收站：已经归档、等待恢复或彻底清理的素材。

首版可以使用同一页面的标签页或分段导航实现，不要求拆成多个路由。

### 6.2 项目资产页

项目详情内继续保留“资产”页面，只展示当前项目的内容：

- 角色、场景、道具、参考和其他素材。
- 章节提取产生的待确认资产。
- 素材版本与当前主版本。
- 素材在章节、镜头和画布中的使用位置。

项目资产页不承担账号级素材清理，不显示其他项目内容。

### 6.3 画布素材选择器

画布中的素材选择器按任务上下文组织：

1. 当前项目素材。
2. 我的素材。
3. 外部素材。
4. 上传新素材。

选择器默认优先展示当前项目素材。无项目画布不展示“当前项目素材”。

## 7. 素材生命周期

```text
生成或上传
  -> 临时结果
      -> 采用到项目 -> 项目素材
      -> 收藏到我的素材 -> 我的素材
      -> 同时采用并收藏 -> 项目素材 + 我的素材
      -> 放弃 -> 回收站

我的素材
  -> 加入项目 -> 增加项目引用，不复制文件

项目素材
  -> 移出项目 -> 删除该项目引用，不删除我的素材和其他项目引用
  -> 收藏 -> 同时进入我的素材

回收站
  -> 恢复 -> 回到进入回收站前的可见范围
  -> 彻底删除 -> 无有效引用时删除记录和文件
```

为了保证画布恢复和任务追踪，底层可以继续保存临时结果的素材记录；用户界面不应因此自动把所有结果都当成“我的素材”。

## 8. 功能需求

### 8.1 素材中心列表

顶部提供：

- 搜索：标题、标签、备注、来源和可检索文本内容。
- 项目筛选：全部项目、未加入项目、指定项目。
- 媒体类型筛选。
- 素材用途筛选。
- 文件夹筛选。
- 排序：最近更新、最近创建、名称、文件大小。

素材卡片优先展示：

- 预览内容。
- 素材名称。
- 媒体类型图标。
- 素材用途。
- 项目数量或“未加入项目”。
- 同步异常标记，仅在异常时展示。

存储供应商、对象键、Data URL 等信息不出现在卡片中。

### 8.2 新增与批量上传

统一“新增素材”入口，支持：

- 上传图片、视频、音频和 3D 模型。
- 新建文本素材。
- 批量上传。
- 导入素材包。
- 从外部素材库导入或引用。

上传时只要求用户选择文件。名称、媒体类型和文件信息自动识别；素材用途、项目和文件夹均为可选项。

上传完成后的默认归属需要在评审中确定，候选方案见“待确认事项”。

### 8.3 素材详情

素材详情分为以下区域：

1. 预览：图片缩放、视频和音频播放、文本查看、3D 预览。
2. 基本信息：名称、素材用途、标签、文件夹、来源和备注。
3. 项目关系：展示已加入的项目，并支持加入项目或移出项目。
4. 使用位置：展示项目、章节、镜头、画布和节点；点击可以跳转定位。
5. 版本：展示历史版本、当前主版本和各版本使用情况。
6. 文件信息：尺寸、时长、格式、大小、创建时间和更新时间。
7. 技术信息：同步状态、存储位置和诊断信息；默认折叠。

项目关系必须显示具体项目名称，不能只显示“已关联项目”。

### 8.4 项目关联

用户可以从以下入口把素材加入项目：

- 素材详情中的“加入项目”。
- 素材卡片批量操作中的“加入项目”。
- 项目资产页中的“从素材中心添加”。
- 画布素材选择器中使用素材时，自动加入当前项目。

加入项目的行为是建立引用，不复制文件。一个素材可以被多个项目引用。

从项目移除前显示影响范围：

- 没有被章节、镜头或画布使用时，可以直接移除。
- 正在被使用时，列出使用位置并阻止直接移除；用户需要先解除引用或替换素材。

### 8.5 生成结果

生成结果完成后必须分别记录以下状态：

- 模型生成状态。
- 结果下载状态。
- 文件保存状态。
- 素材记录状态。
- 项目关联状态。

用户界面合并为可理解的进度和结果：

| 状态 | 用户提示 | 可用操作 |
| --- | --- | --- |
| 全部成功 | 已生成并保存 | 采用、收藏、下载 |
| 已生成但文件未保存 | 结果已生成，保存失败 | 重新保存、下载原结果 |
| 文件已保存但项目未关联 | 结果已保存，尚未加入项目 | 重新关联、查看素材 |
| 仅本机 | 已保存在本机，等待同步 | 重新同步、下载 |
| 同步失败 | 云端同步失败 | 重试同步、导出诊断包 |

重新保存、重新关联和重新同步不得再次调用生成模型，也不得重复计费。

### 8.6 删除与回收站

界面明确区分以下操作：

| 操作 | 影响 |
| --- | --- |
| 从项目移除 | 只删除当前项目引用 |
| 取消收藏 | 不再出现在“我的素材”，保留项目引用和临时记录 |
| 移入回收站 | 从正常素材视图隐藏，保留恢复能力 |
| 彻底删除 | 删除素材记录；实际文件仅在没有任何业务引用时删除 |

所有删除确认框都要展示受影响的项目和使用位置数量。存在有效引用时，不允许彻底删除。

### 8.7 外部素材

Eagle 等外部素材默认保留来源身份。用户使用时可以选择：

- 引用外部素材：保留外部来源，适用于本机工作流。
- 导入 Taiyi：复制到当前资源存储，成为可跨设备使用的 Taiyi 素材。

外部素材不可用时，已经导入 Taiyi 的副本不受影响；仅引用的素材需要明确显示“外部来源不可访问”。

## 9. 状态与数据规则

### 9.1 关系真相源

项目关联以正式的项目素材关联记录为唯一真相源。素材 metadata 中的项目 ID 只能作为缓存，不作为页面最终判断依据。

### 9.2 文件去重

多个素材记录可以在业务需要时引用同一文件资源。删除某条素材记录时，只有确认没有其他素材、项目、画布、任务或外观配置引用后，才允许清理实际文件。

### 9.3 同步状态

同步状态至少包含：

- `synced`：服务器记录和文件均可用。
- `syncing`：正在上传或同步。
- `local_only`：本机存在，服务器尚未保存。
- `failed`：同步失败，可以重试。
- `missing`：记录存在，但文件不可用，需要修复或重新上传。

状态名称仅作为产品合同，具体字段设计在实施方案评审时确定。

### 9.4 素材可见范围

素材需要明确记录以下可见范围，而不是由“是否存在 Asset 记录”推断：

- 是否出现在临时结果。
- 是否被用户收藏。
- 被哪些项目引用。
- 是否进入回收站。

## 10. 权限与安全

- 用户只能查看和管理自己的素材与项目关联。
- 项目归属与素材归属必须由后端校验，不能依赖前端隐藏按钮。
- 公开分享画布只允许读取分享范围内的媒体，不返回素材库管理信息。
- 签名 URL、对象键、Cookie 和第三方 API Key 不进入搜索索引、普通错误提示或导出素材说明。
- 外部素材导入必须遵循现有私网访问和渠道安全限制。

## 11. 异常与恢复

- 页面加载失败时区分“素材列表不可用”和“媒体文件不可用”。
- 本地存在而远程缺失的素材不能静默消失，应进入“待同步”视图。
- 项目关联写入失败时保留素材，并允许只重试关联步骤。
- 文件上传成功但素材记录失败时保留上传会话，允许补建记录。
- 素材记录存在但文件丢失时显示“文件不可用”，提供重新上传、替换文件或查看引用。
- 所有重试操作保持幂等，不能产生重复素材和重复项目引用。

## 12. 迁移策略

现有数据迁移遵循“不丢素材、不扩大删除范围”的原则：

1. 已存在且被项目引用的素材归入“项目素材”。
2. 用户手动创建、上传或明确收藏的素材归入“我的素材”。
3. 仅由生成任务自动创建、未被项目引用且无法确认是否收藏的素材，首版归入“待整理”，不自动删除。
4. 现有自定义分类迁移为文件夹，名称保持不变。
5. 现有业务分类迁移为素材用途。
6. 现有 `metadata.projectIds` 与正式项目关联记录不一致时，以正式关联记录为准，并生成迁移报告。
7. 迁移前后保持素材 ID 和资源引用稳定，避免画布节点失效。

## 13. 分期计划

### 第一期：关系清晰与可靠保存

- 统一界面术语。
- 素材详情展示具体项目与使用位置。
- 支持从素材中心加入项目、从项目资产页添加素材。
- 区分从项目移除、取消收藏、进入回收站和彻底删除。
- 生成结果按阶段展示保存与同步状态，并提供单步重试。
- 项目关联以正式关联记录为准。

### 第二期：临时结果与素材整理

- 增加临时结果或待整理视图。
- 增加收藏到“我的素材”。
- 支持项目筛选、批量加入项目和批量调整用途。
- 外部素材明确区分引用与导入。

### 第三期：智能管理

- AI 自动标签与素材用途建议。
- 相似素材和重复文件检测。
- 自然语言搜索。
- 版权、来源与授权信息管理。
- 团队素材空间及成员权限。

## 14. 验收标准

第一期完成时应满足：

1. 用户从全局素材详情最多三步即可把素材加入指定项目。
2. 素材详情能显示具体项目名称和至少画布或镜头级的使用位置。
3. 用户从项目移除素材时，系统不会删除全局素材或其他项目引用。
4. 有业务引用的素材无法被彻底删除，并能看到阻止删除的原因。
5. 生成完成但关联失败时，用户无需重新生成即可完成关联。
6. 页面中不再同时使用“业务分类”“我的分类”等容易混淆的表述。
7. 本机未同步素材具有明确入口，不会因为远程列表加载成功而从界面消失。
8. 迁移后的历史画布、项目资产和素材预览仍能正常打开。

## 15. 效果指标

- 生成结果成功保存率。
- 生成结果成功关联项目率。
- 同步失败后的恢复成功率。
- 用户从素材中心找到并加入项目的平均操作次数。
- 素材搜索无结果率。
- 因误删或引用丢失产生的诊断事件数量。
- 30 天内跨项目复用素材的用户比例。

## 16. 待确认事项

以下决策会影响第一期交互和数据模型，需要在开发前确认：

1. 用户直接在素材中心上传文件时，默认进入“我的素材”，还是先进入“待整理”。建议默认进入“我的素材”。
2. 画布生成结果是否全部进入“临时结果”，仅在用户点击“采用”后加入项目。建议采用此规则；画布当前主版本可视为自动采用。
3. 无项目画布中采用的结果，是自动收藏到“我的素材”，还是仅保留在该画布。建议仅保留在画布，并提供明显的“收藏”操作。
4. 素材是否允许同时属于多个文件夹。建议第一期维持单文件夹，标签承担多维整理。
5. 第一期开不开“取消收藏”。建议开放，否则“我的素材”和底层素材记录仍然无法分离。
6. 使用位置第一期是否需要定位到具体节点。建议至少支持项目、画布和镜头；节点定位可根据接口成本一起实施。
7. 临时结果保留多久。建议默认 30 天，并允许管理员配置；已被画布、项目或任务引用的结果不得自动清理。
